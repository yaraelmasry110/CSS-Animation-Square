# CSS Animation – Moving Square

## About
A simple web project demonstrating CSS animations using a moving square.

## Features
- Square movement along a rectangular path.
- Color changes during animation.
- Rotation effects.
- Infinite alternate animation.
- Animation pauses when hovering over the square.

## Technologies Used
- HTML5
- CSS3
- CSS Keyframes
- CSS Transforms

## How to Run
Open `animation.html` in a web browser.

## Purpose
Practice CSS animations, keyframes, transforms, and hover interactions.
